# JavaScript If Condition

## Description

This project demonstrates the basic use of **if condition in JavaScript**. It checks whether a given condition is true and executes a specific block of code when the condition is satisfied.

## Concept Used

* JavaScript `if` statement
* Conditional checking
* Comparison operators
* `console.log()`

## Example

```javascript
let age = 20;

if (age >= 18) {
    console.log("You are eligible to vote.");
}
```

### Output

```text
You are eligible to vote.
```

## How It Works

1. A value is stored in a variable.
2. The `if` condition checks the value.
3. If the condition is `true`, the code inside the `if` block is executed.
4. If the condition is `false`, the code inside the block is skipped.

## Technologies Used

* JavaScript

## Purpose

This task is created to practice the fundamentals of **conditional statements in JavaScript** and understand how decisions are made based on conditions.
